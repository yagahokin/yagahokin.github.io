# Lumen

A no-build static website, ready for GitHub Pages.

## Publish with GitHub Pages

1. Create a GitHub repository and upload these files to its main branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, then choose `main` and `/(root)`.
4. Save. GitHub will provide the public URL shortly afterward.

Before publishing, update the studio name, project details, social URLs, and `hello@lumen.studio` in `index.html`.
